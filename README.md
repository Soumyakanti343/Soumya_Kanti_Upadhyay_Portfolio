# Soumya Kanti Upadhyay — Portfolio

A responsive personal portfolio built with **React, Vite, and plain CSS**. It uses a dark theme with blue/cyan accents and includes About, Skills, Projects, Research Experience, Education, Competitive Programming, Achievements, and Contact sections.
